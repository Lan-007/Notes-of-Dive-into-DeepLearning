在 Encoder-Decoder 模型里，解码器生成每个词时，只能依赖编码器最后一个隐藏状态。

Bahdanau提出：Decoder每生成一个词时，查看Encoder所有隐藏状态。（注意力机制）

没有注意力时，编码器通常把整个输入句子压缩进最后一个隐藏状态：$$\mathbf{c}=\mathbf{h}_{T}$$其中：
- $\mathbf h_T$：编码器最后一个时间步的隐藏状态
- $\mathbf c$：上下文向量 context vector
然后解码器每一步都用同一个 $\mathbf c$ 来生成词。

问题是：如果输入句子很长，最后一个隐藏状态很难保存所有信息。
#### 1.Bahdanau 注意力

Decoder 每生成一个词，都看一遍 Encoder 所有隐藏状态，并决定当前最该关注输入句子的哪个位置。

也就是说，上下文向量不再固定：$\mathbf{c}$ ，而是每个解码时间步都有自己的上下文向量：$\mathbf{c}_{t}$
在 Bahdanau 注意力里：

Encoder通常是RNN。

输入：$$x_{1},x_{2},\cdots,x_{T}$$
得到隐藏状态$$h_{1},h_{2},\cdots,h_{T}$$
- Decoder 当前状态是 $\mathbf s_{t-1}$
- 编码器输出序列是 $\mathbf h_1, \mathbf h_2, \ldots, \mathbf h_T$
#### 2.加性注意力

加性注意力公式：$$\alpha(\mathbf{q},\mathbf{k})=\mathbf{w}_{v}^T​tanh(\mathbf{W}_{q}​\mathbf{q}+\mathbf{W}_{k}\mathbf{k})$$
对每个编码器隐藏状态 $\mathbf h_i$ ，都算一个分数：$$e_{t,i}=\alpha(\mathbf{s}_{t-1},\mathbf{h}_{i})$$表示 Decoder 当前状态下和 Encoder 第 $i$ 个词的相关程度
- $t$：当前解码器时间步
- $i$：源句子第 $i$ 个位置
- $e_{t,i}$：当前解码步 $t$ 对输入位置 $i$ 的注意力分数

然后 softmax：$$\alpha_{t,i}=\frac{\exp(e_{t,i})}{\sum_{j=1}^T\exp(e_{t,j})}$$
最后加权求和：                               $\mathbf{c}_{t}=\sum_{i=1}^T\alpha_{t,i}\mathbf{h}_{i}$

总结：每个解码步 t，都用当前解码状态 $s_{t-1}$ 去查询所有编码器状态 $h_i$，然后加权求和得到 $c_t$
#### 3.带注意力的解码器类
```python
class Seq2SeqAttentionDecoder(d2l.AttentionDecoder):  
    def __init__(self, vocab_size, embed_size, num_hiddens,
                 num_layers, dropout=0, **kwargs):     
        super(Seq2SeqAttentionDecoder, self).__init__(**kwargs)  

        self.attention = d2l.AdditiveAttention(         
            num_hiddens,                              # key 的维度
            num_hiddens,                              # query 的维度
            num_hiddens,                              # 注意力隐藏层维度
            dropout                                     
        )

        self.embedding = nn.Embedding(vocab_size, embed_size)  # 词嵌入层

        self.rnn = nn.GRU(                 # GRU 解码器
            embed_size + num_hiddens,      # 输入维度 = 词嵌入维度 + context 维度
            num_hiddens,                   # 隐藏状态维度             
            num_layers,                    # GRU 层数             
            dropout=dropout                             
        )

        self.dense = nn.Linear(num_hiddens, vocab_size)  # 输出层

	def init_state(self, enc_outputs, enc_valid_lens, *args):  # 初始解码器状态
	    outputs, hidden_state = enc_outputs        # 拆开编码器输出和最终隐藏状态
	
	    return (
	        outputs.permute(1, 0, 2),   # 编码器所有时间步输出，改成 batch 在前
	        hidden_state,               # 编码器最终隐藏状态，作为解码器初始隐藏状态
	        enc_valid_lens              # 源句子有效长度，用于 mask padding
	    )

	def forward(self, X, state):           
	    enc_outputs, hidden_state, enc_valid_lens = state # 拆开状态
	
	    X = self.embedding(X).permute(1, 0, 2)    # 词编号->向量，时间步第 0 维
	
	    outputs = []                                     
	
	    self._attention_weights = []                  
	
	    for x in X:                                       # 按时间步遍历
	        query = torch.unsqueeze(hidden_state[-1], dim=1)  # query
	
	        context = self.attention(                   
	            query,                                  # query: 当前解码状态
	            enc_outputs,                            # keys: 编码器所有输出
	            enc_outputs,                            # values: 编码器所有输出
	            enc_valid_lens                          # 有效长度，屏蔽 padding
	        )
	
	        x = torch.cat((context, torch.unsqueeze(x, dim=1)), dim=-1)  
	
	        out, hidden_state = self.rnn(                 # 送入 GRU
	            x.permute(1, 0, 2),                       # 改成 GRU 需要的形状
	            hidden_state                              # 上一时刻隐藏状态
	        )
	
	        outputs.append(out)                           # 保存当前时间步输出
	
	        self._attention_weights.append(self.attention.attention_weights)  
	
	    outputs = self.dense(torch.cat(outputs, dim=0))    
	
	    return outputs.permute(1, 0, 2), [enc_outputs, hidden_state, enc_valid_lens]  # 返回预测结果和新状态
