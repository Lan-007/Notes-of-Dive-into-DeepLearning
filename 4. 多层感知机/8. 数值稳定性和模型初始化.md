遇到 `loss = nan grad = 0` 等问题时，可能是学习率 $\eta$ 不对，也可能来自：
- 权重初始化错误
- 梯度消失
- 梯度爆炸
#### 1.梯度消失

1) 深层神经网络训练时，反向传播要经过很多层。如果每一层传回来的梯度都稍微变小，经过很多层后可能变成接近 0。
2) 现象：loss降得很慢、前面层参数几乎不更新、训练很久也学不动
3) sigmoid容易导致这个问题，因为sigmoid导数最大只有0.25
#### 2.梯度爆炸

1) 如果每一层梯度都稍微变大，经过很多层后可能变得巨大。
2) 现象：loss变成nan、参数变成inf、训练突然崩掉
#### 3.初始化的重要性

1. 大小问题：
初始化太大：前向传播的值太大，loss太大，造成梯度爆炸

初始化太小：输出接近0，梯度接近0，造成梯度消失

2. 对称性问题：

如果神经元初始化完全一样，那么接受一样的输入，得到同样的输出，梯度一样，更新后仍然一样。所以，不能将神经元初始化成相同的值。
3. 让每层输出保持稳定

目的：使得输入的方差大致等于输出的方差，使用Xavier 初始化

4. Xavier 初始化：
对于一个全连接层：`nn.Linear(n_in, n_out)`
$$y=\mathbf{X}\mathbf{w}$$
希望：$$Var(y)=Var(\mathbf{x})$$
Xavier 初始化会让权重方差大概是： $$Var(\mathbf{w})=\frac{2}{n_{in}+n_{out}}$$
```python
def init_weights(m):                         # 定义初始化函数，m 表示网络中的某一层
    if type(m) == nn.Linear:                  
        nn.init.xavier_uniform_(m.weight)     # 用 Xavier 均匀分布初始化权重

net.apply(init_weights)
```
5. 梯度裁剪

为了防止梯度爆炸，通常可以限制梯度大小。

Pytorch通常会默认帮你进行初始化。
