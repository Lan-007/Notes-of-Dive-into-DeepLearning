## 3. 闈炲弬鏁版敞鎰忓姏姹囪仛

鐩镐技搴︼細

$$
\alpha_{i}=\frac{K(x-x_{i})}{\sum_{j}K(x-x_{j})}
$$

K鏄牳鍑芥暟锛岃　閲?$x$ 鍜?$x_{i}$ 鏈夊鍍?
楂樻柉鏍革細

$$

$$

$$
\hat{y}=\sum_{i}\alpha_{i}y_{i}

## 5. 甯﹀弬鏁扮殑 Nadaraya-Watson 妯″瀷

```python
class NWKernelRegression(nn.Module):
    def __init__(self):
        super().__init__()
        self.w = nn.Parameter(torch.rand((1,), requires_grad=True))

    def forward(self, queries, keys, values):
        queries = queries.repeat_interleave(keys.shape[1]).reshape((-1, keys.shape[1]))  # 鎶?query 澶嶅埗鎴愬拰 keys 瀵归綈鐨勫舰鐘?
        self.attention_weights = nn.functional.softmax(   # 璁＄畻娉ㄦ剰鍔涙潈閲?            -((queries - keys) * self.w)**2 / 2,
            dim=1                                         # 瀵硅鍋歴oftmax
        )

        return torch.bmm(                                 # 鎵归噺鐭╅樀涔樻硶
            self.attention_weights.unsqueeze(1),           # 鎶婃敞鎰忓姏鏉冮噸浠?(batch, keys) 鍙樻垚 (batch, 1, keys)
            values.unsqueeze(-1)                           # 鎶?values 浠?(batch, keys) 鍙樻垚 (batch, keys, 1)
        ).reshape(-1)                                      # 杈撳嚭鍙樻垚涓€缁?```
