# 层和块

神经网络不是只能一层一层顺序堆起来。我们可以把若干层封装成一个“块”，再把块组合成更大的模型。

## 1. 层和块

最简单的层:：`nn.Linear(20, 256)`它接收输入，输出结果，同时内部有参数`weight, bias`

但实际模型往往不是单层，而是一组层组合起来：`Linear -> ReLU -> Linear`

这一组层也可以看成一个整体，这个整体就叫 **块 block**。

## 2. nn.Module是所有神经网络块的基类

nn.Module提供参数管理、自动求导、模型保存、设备迁移等功能。PyTorch模型都继承自它

```python
import torch
from torch import nn

class MyModel(nn.Module):      # 类继承
    def __init__(self,input_size,output_size):        # 初始化函数，用来定义层
        super().__init__()     # 调用父类的初始化方法

		self.weight = nn.Parameter( torch.randn(input_size,output_size) )

		self.bias  =  nn.Parameter( torch.zeros(output_size) )
    def forward(self, X):      # 前向传播
        return X@self.weight+self.bias
```

自定义一个MLP块，其中可以写 if、for、while、残差连接等等，具有灵活性

## 3. 自己实现一个 Sequential

```python
class MySequential(nn.Module):
    def __init__(self, *args):                  # *args表示可以接收任意多个层
        super().__init__()

        for idx, module in enumerate(args):     # 遍历每一层得到编号idx
            self._modules[str(idx)] = module    # 把每一层存到 _modules 字典中，键是字符串编号

    def forward(self, X):                       # 前向传播
        for block in self._modules.values():    # 按顺序取出每一个子模块
            X = block(X)                        # X 输入子模块，得到新的 X

        return X                                # 所有模块执行完后，返回最终输出
```
