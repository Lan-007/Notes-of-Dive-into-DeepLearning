
RNN、GRU、LSTM、Encoder-Decoder处理序列数据时一步步读取，不知道具体关注哪里。

Attention提出：不要把所有信息压缩到一个向量，让模型自己选择需要的信息。
```
假设要找一本关于 Transformer 的书。
Query：我想找 Transformer 相关内容
Key：这本书的主题标签，比如 深度学习、NLP、注意力机制
Value：书里的具体内容

用 Query 和每个 Key 比较相似度
相似度越高，对应 Value 权重越大
最后把 Value 加权求和
```
Query 提出问题，Key 用来匹配，Value 提供信息。
#### 1.数学形式

  $Attention(Query, Keys, Values)$
大概流程：
```
1. Query 和每个 Key 算匹配分数
2. 对匹配分数做 softmax，变成权重
3. 用这些权重对 Values 加权求和
```
#### 2.注意力池化(attention pooling)

根据 Query 给每个 Value 不同权重     `eg:输出 = 0.7V1 + 0.2V2 + 0.1V3`
