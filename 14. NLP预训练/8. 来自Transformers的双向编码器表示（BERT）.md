
上下文敏感：
传统词向量( word2vec、Glove )的问题：一个词不管出现在什么上下文里，向量都一样。
BERT：同一个词在不同上下文中，可以得到不同的向量表示。

“双向”：每个位置的 token 表示，都融合左右两边的上下文信息。

BERT使用**Transformer Encoder**原因：Encoder 输入一整段文本，通过自注意力机制让每个 token 关注其他 token ，输出每个 token 的上下文表示。这一特点非常适合文本理解任务。

|模型|上下文方向|下游使用方式|
|---|---|---|
|word2vec/GloVe|无上下文|固定词向量|
|ELMo|双向|通常冻结模型，加入任务专用架构|
|早期 GPT|从左向右|统一预训练主干并微调|
|BERT|双向|统一预训练主干并微调|
#### 1.输入：token embedding + segment embedding + position embedding

Token Embedding：token本身的向量
Segment Embedding：不同句子不同的segment embedding
Position Embedding：位置embedding

BERT输入里两个特殊的token：`[CLS]和[SEP]`

$eg:$ `[CLS] I love deep learning [SEP]`

`[CLS]` 的最终输出向量通常用来代表整句话，可以用于文本分类。
`[SEP]` 用来分隔句子
```python
class BERTEncoder(nn.Module):
    """BERT编码器"""

    def __init__(
        self,
        vocab_size,
        num_hiddens,
        norm_shape,
        ffn_num_input,
        ffn_num_hiddens,
        num_heads,
        num_layers,
        dropout,
        max_len=1000,
        key_size=768,
        query_size=768,
        value_size=768,
        **kwargs
    ):
        super(BERTEncoder, self).__init__(**kwargs)

        self.token_embedding = nn.Embedding(
            vocab_size,
            num_hiddens
        )

        self.segment_embedding = nn.Embedding(
            2,
            num_hiddens
        )

        self.blks = nn.Sequential()

        for i in range(num_layers):
            self.blks.add_module(
                f"{i}",
                d2l.EncoderBlock(
                    key_size,
                    query_size,
                    value_size,
                    num_hiddens,
                    norm_shape,
                    ffn_num_input,
                    ffn_num_hiddens,
                    num_heads,
                    dropout,
                    True
                )
            )

        self.pos_embedding = nn.Parameter(
            torch.randn(
                1,
                max_len,
                num_hiddens
            )
        )
	def forward(
		self,
		tokens,
		segments,
		valid_lens
		):
		X = (self.token_embedding(tokens) + self.segment_embedding(segments))
		
		X = X + self.pos_embedding.data[:, :X.shape[1], :]
		
		for blk in self.blks:
			X = blk(X, valid_lens)
		
		return X
```
#### 2.训练任务：自减监督学习
##### 1）掩蔽语言模型 MLM（Masked Language Modeling）

随机遮住句子中的一些 token，让模型根据上下文把它们预测出来。

BERT 随机选取输入中约 15% 的普通词元作为预测目标。对于已经被选中的 15% 词元：

BERT 训练时会随机选择一部分 token，比如 15%，对这些被选中的 token，处理方式通常是：

|     处理方式     | 比例  |        例子        |
| :----------: | :-: | :--------------: |
| 替换成 `[MASK]` | 80% | `deep -> [MASK]` |
| 替换成随机 token  | 10% | `deep -> apple`  |
|     保持不变     | 10% |  `deep -> deep`  |
因为真实输入中，不会出现 `[MASK]`，所以进行随机替换和保持不变。
```python
class MaskLM(nn.Module):
    """BERT的掩蔽语言模型任务"""

    def __init__(
        self,
        vocab_size,
        num_hiddens,
        num_inputs=768,
        **kwargs
    ):
        super(MaskLM, self).__init__(**kwargs)

        self.mlp = nn.Sequential(
            nn.Linear(
                num_inputs,
                num_hiddens
            ),
            nn.ReLU(),
            nn.LayerNorm(num_hiddens),
            nn.Linear(
                num_hiddens,
                vocab_size
            )
        )

	def forward(self, X, pred_positions):
	    num_pred_positions = pred_positions.shape[1]
	
	    pred_positions = pred_positions.reshape(-1)
	
	    batch_size = X.shape[0]
	
	    batch_idx = torch.arange(0, batch_size)
	
	    batch_idx = torch.repeat_interleave( batch_idx, num_pred_positions)
	
	    masked_X = X[batch_idx, pred_positions]
	
	    masked_X = masked_X.reshape((batch_size,num_pred_positions,-1) )
	
	    mlm_Y_hat = self.mlp(masked_X)

    return mlm_Y_hat

loss = nn.CrossEntropyLoss( reduction='none' )
```
#### 2)下一句预测 NSP (Next Sentence Prediction)

判断第二个句子是不是第一个句子的下一句。

生成预训练数据时：
- 50% 使用真实连续句子；
- 50% 把第二句话替换为随机句子。
```python
class NextSentencePred(nn.Module):
    """BERT的下一句预测任务"""

    def __init__(self, num_inputs, **kwargs):
        super(
            NextSentencePred,
            self
        ).__init__(**kwargs)

        self.output = nn.Linear(
            num_inputs,
            2
        )

    def forward(self, X):
        return self.output(X)

loss = nn.CrossEntropyLoss( reduction='none' )
```
### 3.BERT模型

```python
class BERTModel(nn.Module):
    """BERT模型"""

    def __init__(
        self,
        vocab_size,
        num_hiddens,
        norm_shape,
        ffn_num_input,
        ffn_num_hiddens,
        num_heads,
        num_layers,
        dropout,
        max_len=1000,
        key_size=768,
        query_size=768,
        value_size=768,
        hid_in_features=768,
        mlm_in_features=768,
        nsp_in_features=768
    ):
        super(BERTModel, self).__init__()

		# 编码器：负责每个位置的上下文化表示
        self.encoder = BERTEncoder(
            vocab_size,
            num_hiddens,
            norm_shape,
            ffn_num_input,
            ffn_num_hiddens,
            num_heads,
            num_layers,
            dropout,
            max_len=max_len,
            key_size=key_size,
            query_size=query_size,
            value_size=value_size
        )

		# 处理 <cls> 的隐藏状态
        self.hidden = nn.Sequential(
            nn.Linear(
                hid_in_features,
                num_hiddens
            ),
            nn.Tanh()
        )
		# 两个任务头
        self.mlm = MaskLM(
            vocab_size,
            num_hiddens,
            mlm_in_features
        )

        self.nsp = NextSentencePred(
            nsp_in_features
        )

	def forward(
	    self,
	    tokens,
	    segments,
	    valid_lens=None,
	    pred_positions=None
	):
	    encoded_X = self.encoder(
	        tokens,
	        segments,
	        valid_lens
	    )
	
	    if pred_positions is not None:
	        mlm_Y_hat = self.mlm(
	            encoded_X,
	            pred_positions
	        )
	    else:
	        mlm_Y_hat = None
	
	    nsp_Y_hat = self.nsp(
	        self.hidden(
	            encoded_X[:, 0, :]
	        )
	    )

	    return (
	        encoded_X,
	        mlm_Y_hat,
	        nsp_Y_hat
	    )
```

##### 1.预训练阶段

$输入语料库\to构造MLM和NSP标签\to训练BERT\space Encoder$ 
##### 2.微调阶段

针对具体任务增加简单输出层。

文本分类：$<cls>表示 \to 线性分类层 ↓ 情感类别$

命名实体分类：$每个词元的表示 \to 逐词分类层 \to 人名/地点/组织/其他$

问答：$每个词元的表示 \to 预测答案开始位置和结束位置$
