##### 1.生成合成数据集
假设真实规律是：$$\mathbf{w}=\begin{bmatrix} 2\\ -3.4 \end{bmatrix}, \quad b=4.2$$生成数据：
```python
def synthetic_data(w, b, num_examples):
	"""生成 y = Xw + b + 噪声"""
	
	X = torch.normal(0,1,(num_examples, len(w))) # 正态分布
	
	y = torch.matmul(X, w) + b
	
	y += torch.normal(0,0.01, y.shape)
	
	return X, y.reshape((-1,1)) #调整为列向量，与模型输出匹配
```
##### 2.小批量数据迭代器：
```python
def data_iter(batch_size, features, labels):
	”“"把整个训练数据随机打乱，每次返回batch个样本”“”
	
	num_examples = len(features)
	
	indices = list(range(num_examples))  # 列表中的元素为编号
	
	random.shuffle(indices)              # 打乱编号
	
	for i in range(0, num_examples, batch_size):
		batch_indices = torch.tensor(indices[i:min(i + batch_size, num_examples)])
		yield features[batch_indices], labels[batch_indices]
		#不会一次返回所有batch，而是每次要数据时才生成下一个batch
```
##### 3.初始化参数
```python
w = torch.normal(0,0.01, size=(2,1),requires_grad=True)

b = torch.zeros(1, requires_grad=True)
```
##### 4.定义模型
```python
def linreg(X, w, b):
	"""线性回归模型"""
	return torch.matmul(X, w)+b
```
$$\hat{y} = \mathbf{X}\mathbf{w}+b$$
##### 5.定义平方损失
```python
def squard_loss(y_hat, y):
	""均方损失“”
	return (y_hat - y.reshape(y_hat.shape))**2 /2
```
y.reshape: 防止y.shape为(10,)与(10,1)触发广播产生(10,10)结果
##### 6.优化算法：随机梯度下降
```python
def sgd(params, lr, batch_size):
	"""小批量随机梯度下降"""
	with torch.no_grad():
		for param in params:
			param -= lr * param.grad / batch_size
			param.grad.zero_()
```
$$\theta\leftarrow \theta-\frac{\eta}{B}\nabla _{\theta}L_{batch}$$
这里损失在训练循环中使用 `l.sum()` 汇总。
如果用`l.mean().backward()` 就不能再除一次batch_size
#### 7.完整训练循环
```python
lr = 0.03
num_epochs = 3
net = linreg
loss = squard_loss

for epoch in range(num_epochs):
	for X,y in data_iter(batch_size, features, labels):
	
		l = loss(net(X, w, b), y)
		
		l.sum().backward()
		
		sgd([w, b], lr, batch_size)
		
	with torch.no_grad():
		train_l = loss(net(features, w, b), labels)
		print(f'epoch {epoch+1}, loss {float(train_l.mean()):f}')
