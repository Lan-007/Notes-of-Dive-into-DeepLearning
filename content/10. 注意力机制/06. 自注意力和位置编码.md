# 自注意力和位置编码

**自注意力**：一个序列内部每个token直接看到其他token。(替代RNN、CNN)
**位置编码**：Attention没有顺序概念，Transformer如何知道词的位置。

## 1. 自注意力

Bahdanau 注意力：Query 来自 Decoder，Key 和 Value 来自 Encoder。
自注意力：Query、Key、Value 都来自同一个输入序列。

输入序列： $\mathbf{X}\in R^{n\times d}$
自注意力会直接生成：

$$
\mathbf{Q}=\mathbf{X}\mathbf{W}_{q}
$$

$$
\mathbf{K}=\mathbf{X}\mathbf{W}_{k}
$$

$$
\mathbf{V}=\mathbf{X}\mathbf{W}_{v}
$$

也就是说：每个 token 都可以看序列中的其他 token，并根据相关性汇总信息。

|矩阵|含义|
|---|---|
|$\mathbf Q$|当前 token 想找什么信息|
|$\mathbf K$|每个 token 提供什么匹配标签|
|$\mathbf V$|每个 token 真正携带的信息|

```python
num_hiddens = 100  # 隐藏维度是 100
num_heads = 5

attention = MultiHeadAttention(
    num_hiddens,                 # key 的输入维度
    num_hiddens,                 # query 的输入维度
    num_hiddens,                 # value 的输入维度
    num_hiddens,                 # num_hiddens，输出隐藏维度
    num_heads,                   # 多头数量
    0.5                          # dropout概率
)

batch_size = 2
num_queries = 4  # 每个样本有 4 个 token

valid_lens = torch.tensor([3, 2])  # 第一个样本有效长度是 3，第二个样本有效长度是 2

X = torch.ones((batch_size, num_queries, num_hiddens))  # 输入 X，形状是 (2, 4, 100)

attention(X, X, X, valid_lens).shape  # 自注意力：queries、keys、values 都是 X
```

在 RNN 里，第 1 个词的信息要一步步传到第 100 个词，路径很长。而在自注意力里，第 100 个词可以直接关注第 1 个词。路径长度是：$O(1)$

所以 Transformer 更容易建模长距离依赖。

## 2. 位置编码

但自注意力本身不关心 token 的顺序，如果两个句子词一样，但顺序不同，含义则不同。

如果只看 token 集合，不看顺序，模型就分不清这两个句子的区别，所以需要位置编码，给每个 token 加入位置信息。从 $embedding$ 变成 $embedding+position$ .

使用向量形式的位置编码。

正弦位置编码公式：
设位置为 $i$，维度为 $j$，隐藏维度为 $d$。
偶数维：

$$
p_{i,2j}=\sin\left( \frac{i}{10000^{2j/d}} \right)
$$

奇数维：

$$
p_{i,2j+1}=\cos\left( \frac{i}{10000^{2j/d}} \right)
$$

这里：
- $p_{i,2j}$：位置 $i$ 在偶数维的编码
- $p_{i,2j+1}$：位置 $i$ 在奇数维的编码

```python
class PositionalEncoding(nn.Module):
    def __init__(self, num_hiddens, dropout, max_len=1000):
        super(PositionalEncoding, self).__init__()

        self.dropout = nn.Dropout(dropout)

        self.P = torch.zeros((1, max_len, num_hiddens))

        X = torch.arange(max_len, dtype=torch.float32).reshape(-1, 1) / torch.pow(
            10000,
            torch.arange(0, num_hiddens, 2, dtype=torch.float32) / num_hiddens
        )

        self.P[:, :, 0::2] = torch.sin(X)

        self.P[:, :, 1::2] = torch.cos(X)

    def forward(self, X):
        X = X + self.P[:, :X.shape[1], :].to(X.device)    # 把位置编码加到输入X上

        return self.dropout(X)                                # 返回 dropout 后的结果
```
