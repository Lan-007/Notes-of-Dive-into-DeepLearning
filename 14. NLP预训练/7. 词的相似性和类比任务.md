##### 1.词相似性

给定一个词，找出最接近的词。
常用：余弦相似度（两个向量夹角的余弦）$$\cos(\mathbf{x},\mathbf{y})=\frac{\mathbf{x}^T\mathbf{y}}{\lVert \mathbf{x} \rVert_2\lVert \mathbf{y} \rVert_2}$$
范围为 $-1\sim1$ , 越接近1，说明两个词越相似，接近0说明关系不明显，接近-1，方向相反
```python
def knn(W, x, k):
    cos = torch.mv(W, x.reshape(-1,)) / (
        torch.sqrt(torch.sum(W * W, axis=1) + 1e-9)
        * torch.sqrt((x * x).sum())
    )
    _, topk = torch.topk(cos, k=k)              # 找出相似度最高的 k 个词
    return topk, [cos[int(i)] for i in topk]
```

#### 3.局限性
##### 1）不是所有关系都是线性的

有些关系能够近似表现为固定方向：

```
现在式 → 过去式
原级 → 最高级
首都 → 国家
```

但复杂语义关系不一定能通过简单的向量加减表示。
##### 2）容易受到语料偏见影响
##### 3）静态词向量无法处理一词多义
##### 4）相似不等于同义，可能仅仅出现在相似上下文中
