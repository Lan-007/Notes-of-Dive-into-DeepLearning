CSV 中往往有缺失值、文本类别和不规则字段，模型不能直接读。
例如一个不规则的数据集data_file：
```
NumRooms,Alley,Price
NA,Pave,127500
2,NA,106000
4,NA,178100
NA,NA,140000
```
1. 读入：
```python
import pandas as pd

data = pd.read_csv(data_file)# DataFrame
data.iloc(:,0:2)             # 前两列，为DataFrame
data.iloc(:, 2)              # 最后一列，为Series

inputs, outputs = data.iloc[, 0:2], data.iloc[:, 2]
```
2. 缺失值处理
数值类型：均值填补
```python
inputs = inputs.fillna(inputs.mean())
```
```
   NumRooms Alley
0       3.0  Pave
1       2.0   NaN
2       4.0   NaN
3       3.0   NaN
```
字符串类型：分类，独热编码
```python
inputs = pd.get_dummies(inputs, dummy_na=True)
```
```
   NumRooms  Alley_Pave  Alley_nan
0       3.0           1          0
1       2.0           0          1
2       4.0           0          1
3       3.0           0          1
```
3. 转为tensor
```python
import torch

X = torch.tensor(inputs.to_numpy(dtype=float), dtype=torch.float32)
y = torch.tensor(outputs.to_numpy(dtype=float),dtype=torch.float32)

X.shape # torch.Size([4, 3]) 
y.shape # torch.Size([4])
