# 线性代数

1. 点积

```python
x = torch.tensor([0., 1., 2., 3.])
y = torch.ones(4)

torch.dot(x, y)
# tensor(6.)

torch.sum(x * y)
# tensor(6.)
```

2. 矩阵-向量乘法

```python
A.shape  # (5, 4)
x.shape  # (4,)

torch.mv(A, x).shape
# (5,)
```

3. 矩阵-矩阵乘法
(n, k) @ (k, m) → (n, m)

```python
A = torch.arange(20, dtype=torch.float32).reshape(5, 4)
B = torch.ones(4, 3)

A @ B
# 形状是 (5, 3)
```
