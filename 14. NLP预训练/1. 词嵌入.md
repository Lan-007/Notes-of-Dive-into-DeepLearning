#### 1.、词嵌入（Word2Vec）

把一个词转换成一个包含语义信息的向量。（embedding）
如何用向量表示意义？训练后，相似词距离更近。

one-hot -> Word2Vec ：独热向量无法表达相似度，通常使用余弦相似度。且独热向量维度太高。

Word2Vec：一个词的含义，可以通过它周围出现的词推断。(自监督学习)
#### 2.连续词袋模型CBOW（Continuous Bag Of Words）

根据上下文 $w_{o}$ 预测中心词 $w_{c}$
目标：最大化$$P(w_{c}|\mathcal{C})$$
其中 $\mathcal{C}$：上下文词集合

CBOW 会先把上下文词的向量求平均：$$\overline{\mathbf{v}}=\frac{1}{|\mathcal{C}|}\sum_{i\in \mathcal{C}}\mathbf{v}_{i}$$
然后用这个平均向量预测中心词：$$P(w_{c}|\mathcal{C})=\frac{\exp(\mathbf{u}_{c}^T\overline{\mathbf{v}})}{\sum_{j\in\mathcal{V}}\exp(\mathbf{u}_{j}^T\overline{\mathbf{v}})}$$
#### 3.跳元模型Skip-Gram

根据中心词 $w_{c}$ 预测上下文 $w_{o}$
目标：最大化$$\prod_{o\in\mathcal{C}}P(w_{o}|w_{c})$$其中 $\mathcal{C}$ ：上下文词集合

每个词有两个向量：
1. 作为中心词时的向量： $\mathbf{v}_{c}$
2. 作为上下文词时的向量： $\mathbf{u}_{o}$

两个词的相似度： $\mathbf{u_{o}^T}\cdot\mathbf{v}_{c}$ 
然后通过 softmax 得到概率：$$P(w_{o}|w_{c})=\frac{\exp(\mathbf{u_{o}^T}\mathbf{v}_{c})}{\sum_{i\in\mathcal{V}}exp(\mathbf{u_{i}^T}\mathbf{v}_{c})}$$
这里 $\mathcal{V}$：整个词表
#### 3.数学思想

如果两个词经常一起出现，它们的点积要变大：$\mathbf{u}_{o}^T\mathbf{v}_{c}$

损失函数：多分类交叉熵 $-logP(w_{o}\mid w_{c})$
##### 4.Embedding

本质上就是一个可以训练的矩阵。

假设：
- 词表大小是 $V$
- 每个词向量维度是 $d$
那么 embedding 矩阵是： $\mathbf{E}\in R^{V\times d}$
```python
import torch                                
from torch import nn                          

embedding = nn.Embedding(                     # 创建一个词嵌入层
    num_embeddings=5,                         # 词表大小是 5
    embedding_dim=3                           # 每个词被表示成 3 维向量
)

token_ids = torch.tensor([0, 2, 4])           # 输入token id

vectors = embedding(token_ids)                # 输入token id,得到词向量

print(vectors)                                # 打印这3个token对应的向量
