# GPU

怎么把张量和模型放到 GPU 上计算。
GPU：并行计算，适合大量矩阵乘法。

## 1. device

```python
import torch

torch.device('cpu') # 表示 CPU 设备
torch.device('cuda:0') # 表示第 0 块 GPU

torch.cuda.device_count()  # 返回 GPU 数量
```

## 2. 通常写法

```python
device = torch.device('cuda' if torch.cuda.is_available() else 'cpu')

net = net.to(device)

for X, y in train_iter:
    X = X.to(device)
    y = y.to(device)

    y_hat = net(X)            # 前向传播，此时模型和数据在同一设备
    l = loss(y_hat, y)

    optimizer.zero_grad()
    l.backward()
    optimizer.step()
```

NumPy 只能处理 CPU 上的数据。如果张量在 GPU 上，不能直接numpy。

```python
x_np = x_gpu.detach().cpu().numpy()
```

## 3. 保存到cpu

```python
state_dict = torch.load('model.pth', map_location='cpu')  # 保存到cpu

model.load_state_dict(state_dict)                         # 加载参数
```
