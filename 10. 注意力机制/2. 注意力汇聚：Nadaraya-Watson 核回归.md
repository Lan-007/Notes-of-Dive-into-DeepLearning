注意力到底如何实现信息选择？注意力汇聚。

给定一个 $x$ ，预测对应的 $y$ 。 

核回归：预测时不是直接套一个线性层，而是看训练集中哪些 $x$ 和当前 $x$ 更接近，然后给它们更高权重。
#### 1.Nadaraya-Watson核回归

思想：想预测`x = 1.2 时的 y`
`离当前 x 越近的训练样本，权重越大；离当前 x 越远的训练样本，权重越小。`
$$f(x)=\sum_{i} attention_{weight}(x,x_{i})*y_{i}$$

| 注意力术语 | 在核回归里的含义               |
| ----- | ---------------------- |
| Query | 当前要预测的 $x$             |
| Key   | 训练集里的 $x_{i}$          |
| Value | 训练集里的 $y_i$            |
| 注意力权重 | 当前 $x$ 和每个 $x_i$ 的相似程度 |
| 输出    | 对所有 $y_i$ 的加权平均        |
#### 2.生成数据集
```python
# 真实函数
def f(x):                          
	return 2*torch.sin(x) + x**0.8 # y = 2sin(x) + x^0.8

# 生成训练数据
n_train = 50
x_train, _ = torch.sort(torch.rand(n_train)*5) # 生成50个0~5之间的随机数，排序
y_train = f(x_train) +torch.normal(0.0, 0.5, (n_train,)) # 标准差0.5

# 生成测试数据
x_test = torch.arange(0, 5, 0.1) # 不含5
y_test = f(x_test)
n_test = len(x_test) 

# 平均汇聚
y_hat = torch.repeat_interleave(y_train.mean(), n_test) # 不管x是多少y都一样
```
#### 3.非参数注意力汇聚

相似度：$$\alpha_{i}=\frac{K(x-x_{i})}{\sum_{j}K(x-x_{j})}$$
K是核函数，衡量 $x$ 和 $x_{i}$ 有多像

高斯核：$$K(x)=e^{-x^2/2}$$
距离越近值越大
然后预测：$$\hat{y}=\sum_{i}\alpha_{i}y_{i}$$
```python
# 把每个测试点重复 n_train 次。
X_repeat = x_test.repeat_interleave(n_train).reshape((-1, n_train))

attention_weights = nn.functional.softmax(
    -(X_repeat - x_train)**2 / 2,   # 每个测试点和所有训练点做差
    dim=1                           # 对每一行做softmax
)

# 预测
y_hat = torch.matmul(attention_weights, y_train)
```
对应QKV
```
Query：x_test 
Key：x_train 
Value：y_train
```
#### 4.带参数的注意力汇聚
$$\alpha_{i}=softmax(-\frac{1}{2}((x_{i}-x)*w)^2)$$
加入 $w$ 学习距离的重要程度。

$w$ 大：稍微远一点的权重迅速变小，注意力更集中
$w$ 小： 远一点的也还有权重，注意力更分散
#### 5.带参数的 Nadaraya-Watson 模型
```python
class NWKernelRegression(nn.Module):                
    def __init__(self):                                 
        super().__init__()                            
        self.w = nn.Parameter(torch.rand((1,), requires_grad=True))

    def forward(self, queries, keys, values):     
        queries = queries.repeat_interleave(keys.shape[1]).reshape((-1, keys.shape[1]))  # 把 query 复制成和 keys 对齐的形状

        self.attention_weights = nn.functional.softmax(   # 计算注意力权重
            -((queries - keys) * self.w)**2 / 2,          
            dim=1                                         # 对行做softmax
        )

        return torch.bmm(                                 # 批量矩阵乘法
            self.attention_weights.unsqueeze(1),           # 把注意力权重从 (batch, keys) 变成 (batch, 1, keys)
            values.unsqueeze(-1)                           # 把 values 从 (batch, keys) 变成 (batch, keys, 1)
        ).reshape(-1)                                      # 输出变成一维
```
#### 6.构造训练用的 keys 和 values
```python
X_tile = x_train.repeat((n_train, 1))  # 把 x_train 重复 n_train 行
Y_tile = y_train.repeat((n_train, 1))  # 把 y_train 重复 n_train 行

keys = X_tile[(1 - torch.eye(n_train)).type(torch.bool)].reshape((n_train, -1))  # 去掉每一行中对应自己的 x

values = Y_tile[(1 - torch.eye(n_train)).type(torch.bool)].reshape((n_train, -1))  # 去掉每一行中对应自己的 y
```
#### 7.训练模型
```python
net = NWKernelRegression()  # 创建带参数的核回归模型

loss = nn.MSELoss(reduction='none')  # 使用均方误差损失，返回每个样本自己的 loss

trainer = torch.optim.SGD(net.parameters(), lr=0.5)  # 使用 SGD 优化器

for epoch in range(5):  # 训练 5 轮
    trainer.zero_grad()  # 清空上一轮梯度

    l = loss(net(x_train, keys, values), y_train)  # 前向传播

    l.sum().backward()  # 反向传播，计算参数 w 的梯度

    trainer.step()  # 更新参数 w

    print(f'epoch {epoch + 1}, loss {float(l.sum()):.6f}')  # 打印当前总损失
