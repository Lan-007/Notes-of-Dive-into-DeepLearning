# 注意力评分函数

Query 和 Key 到底怎么“匹配”？这个相似度分数怎么算？

## 1. 注意力评分函数

注意力机制

$$
f(\mathbf{q},(\mathbf{k_{1}},\mathbf{v_{1}}),\cdots,(\mathbf{k_{m}}\mathbf{v_{m}}))=\sum_{i=1}^m\alpha(\mathbf{q},\mathbf{k_{i}})\mathbf{v_{i}}
$$

注意力评分函数：

$$
\alpha(\mathbf{q},\mathbf{k_{i}})
$$

注意力权重一般由 softmax 得到：

$$
\alpha(\mathbf{q},\mathbf{k_{i}})=\frac{\exp(\alpha(\mathbf{q,}\mathbf{k_{i}}))}{\sum_{j=1}^m\exp(\alpha(\mathbf{q},\mathbf{k_{j}}))}
$$

## 2. 注意力流程

第一步：打分 $s_{i}=\alpha(\mathbf{q},\mathbf{k_{i}})$
第二步：softmax归一化

$$
\alpha_{i}=softmax(s_{i})
$$

第三步：加权求和

$$
\mathbf{o}=\sum_{i}\alpha_{i}\mathbf{v_{i}}
$$

## 3. masked softmax

在自然语言处理中，一个 batch 里的句子长度通常不一样。为了组成 batch，短句子要补 padding：

```text
句子 A：我 爱 机器 学习
句子 B：你好 <pad> <pad> <pad>
```

但是 `<pad>` 不是真实词，模型不应该关注它。
所以做 softmax 时，要把 padding 位置屏蔽掉。

```python
def masked_softmax(X, valid_lens):                         # X 是注意力分数
										        # valid_lens 是每个样本的有效长度
    if valid_lens is None:
        return nn.functional.softmax(X, dim=-1)

    else:                                                  # 如果传入了有效长度
        shape = X.shape

        if valid_lens.dim() == 1:                          #  (batch_size,)
            valid_lens = torch.repeat_interleave(valid_lens, shape[1])

        else:                                              # 二维
            valid_lens = valid_lens.reshape(-1)            # 拉平成一维

        X = d2l.sequence_mask(X.reshape(-1, shape[-1]), valid_lens,value=-1e6)

        return nn.functional.softmax( X.reshape(shape),  dim=-1)
```

无效位置填 `-1e6` sofrmax权重接近0

## 4. 加性注意力

加性注意力适合query 和 key 维度不一样的情况。评分函数：

$$
\alpha(\mathbf{q},\mathbf{k})=\mathbf{w}_{v}^T\tanh(\mathbf{W}_{q}\mathbf{q}+\mathbf{W}_{k}\mathbf{k})
$$

- $\mathbf W_q$：把 query 投影到隐藏空间
- $\mathbf W_k$：把 key 投影到隐藏空间
- $\mathbf w_v$：把隐藏表示变成一个标量分数
- $\tanh$：非线性激活函数，增加模型表达能力

```python
class AdditiveAttention(nn.Module):                         # 定义加性注意力层
    def __init__(self, key_size, query_size, num_hiddens, dropout, **kwargs):
        super(AdditiveAttention, self).__init__(**kwargs)

        self.W_k = nn.Linear(key_size, num_hiddens, bias=False)
        self.W_q = nn.Linear(query_size, num_hiddens, bias=False)
        self.w_v = nn.Linear(num_hiddens, 1, bias=False)

        self.dropout = nn.Dropout(dropout)

    def forward(self, queries, keys, values, valid_lens):     # 前向传播
        queries = self.W_q(queries)
        keys = self.W_k(keys)

        features = queries.unsqueeze(2) + keys.unsqueeze(1)   # 两两组合

        features = torch.tanh(features)

        scores = self.w_v(features).squeeze(-1)

        self.attention_weights = masked_softmax(scores, valid_lens)

        return torch.bmm(self.dropout(self.attention_weights), values)
```

## 5. 缩放点积注意力 (Scaled Dot-Product Attention)

如果 query 和 key 的维度一样，就可以直接点积打分。评分函数：

$$
\alpha(\mathbf{q},\mathbf{k})=\frac{\mathbf{q}^{T}\cdot\mathbf{k}}{\sqrt{ d }}
$$

- $d$ 是 query/key 的维度
- $\mathbf q^\top \mathbf k$ 是点积
- $\sqrt d$ 是缩放因子

如果 $d$ 很大，点积：$\mathbf{q}^T\mathbf{k}$ 可能数值很大。softmax 输入过大时，会导致分布特别尖锐：
	某一个位置权重接近 1 ，其他位置接近 0

除以$\sqrt{ d }$ 可以控制分数大小，让 softmax 更稳定。

```python
class DotProductAttention(nn.Module):
    def __init__(self, dropout, **kwargs):
        super(DotProductAttention, self).__init__(**kwargs)

        self.dropout = nn.Dropout(dropout)

    def forward(self, queries, keys, values, valid_lens=None):
        d = queries.shape[-1]

        scores = torch.bmm(
            queries,
            keys.transpose(1, 2)
        ) / math.sqrt(d)

        self.attention_weights = masked_softmax(scores, valid_lens)

        return torch.bmm(self.dropout(self.attention_weights), values)
```
