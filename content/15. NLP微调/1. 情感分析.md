# 情感分析

输入一段长度不固定的电影评论，判断它是积极评论还是消极评论。

```text
输入：多个词元构成的序列
输出：整个序列的一个标签(二分类)
```

使用IMDb电影评论数据集：
- 25000条训练评论；
- 25000条测试评论；
- 每个集合中正、负样本数量相同；
- 因此随机猜测的准确率约为50%。

数据目录：

```text
aclImdb/
├── train/
│   ├── pos/   # 正面影评
│   └── neg/   # 负面影评
└── test/
    ├── pos/
    └── neg/
```

## 1. 数据集

1. 读取数据

```python
def read_imdb(data_dir, is_train):
    """读取IMDb评论数据集文本序列和标签"""
    data, labels = [], []
    for label in ('pos', 'neg'):
        folder_name = os.path.join(
            data_dir,
            'train' if is_train else 'test',
            label
        )

        for file in os.listdir(folder_name):
            with open(os.path.join(folder_name, file), 'rb') as f:
                review = f.read().decode('utf-8').replace('\n', '')
                data.append(review)
                labels.append(1 if label == 'pos' else 0)

    return data, labels

train_data = read_imdb(data_dir, is_train=True)
```

2. 分词与词表

$文本 → token → token id → 张量$

## 2. 使用循环神经网络(RNN)

按顺序读完整段文本，再提取整体含义。

$影评 token id→ GloVe 词向量→ 双向 LSTM→ 序列表示→全连接层→ 积极 / 消极$

1. 预训练Glove

IMDb 训练集只有 25,000 条影评，不算特别大。若从随机词向量开始训练（从零训练），模型容易过拟合，也不容易学到足够好的语言知识。原书加载在大规模语料上预训练的 GloVe：

```python
glove_embedding = d2l.TokenEmbedding('glove.6b.100d')
```

但GloVe只提供单词表示，还没有提供整条评论的表示，因此需要双向LSTM继续编码序列。

2. BiRNN模型

```python
class BiRNN(nn.Module):
    def __init__(self, vocab_size, embed_size, num_hiddens, num_layers):
        super(BiRNN, self).__init__()

        self.embedding = nn.Embedding(vocab_size, embed_size)

        self.encoder = nn.LSTM(
            embed_size,
            num_hiddens,
            num_layers=num_layers,
            bidirectional=True
        )

        self.decoder = nn.Linear(4 * num_hiddens, 2)
	# 双向 LSTM
    def forward(self, inputs):
        embeddings = self.embedding(inputs.T)
        self.encoder.flatten_parameters()

        outputs, _ = self.encoder(embeddings)

        encoding = torch.cat((outputs[0], outputs[-1]), dim=1)

        outs = self.decoder(encoding)
        return outs
```

3. 初始化模型及权重

```python
embed_size = 100
num_hiddens = 100
num_layers = 2

devices = d2l.try_all_gpus()

net = BiRNN(
    len(vocab),
    embed_size,
    num_hiddens,
    num_layers
)

def init_weights(m):
    if type(m) == nn.Linear:
        nn.init.xavier_uniform_(m.weight)

    if type(m) == nn.LSTM:
        for param in m._flat_weights_names:
            if "weight" in param:
                nn.init.xavier_uniform_(
                    m._parameters[param]
                )

net.apply(init_weights)
```

4. 加载并冻结 GloVe

```python
embeds = glove_embedding[vocab.idx_to_token]

net.embedding.weight.data.copy_(embeds)
net.embedding.weight.requires_grad = False
```

冻结后不会保存和更新梯度，不会改变这些词向量，LSTM和全连接层仍正常训练。

5. 训练

```python
lr, num_epochs = 0.01, 5

trainer = torch.optim.Adam(net.parameters(), lr=lr)
loss = nn.CrossEntropyLoss(reduction="none")

d2l.train_ch13(
    net, train_iter, test_iter,
    loss, trainer, num_epochs, devices
)
```

6. 局限

没有显式处理有效长度，可能处理大量`<pad>`、LSTM难以并行

## 3. 使用卷积神经网络(TextCNN)

扫描局部短语，发现局部情感模式。

$token id→ 两套词向量→ 变宽一维卷积→ 全局池化：每个卷积核只保留最强响应→ 拼接→ 全连接分类$

1. TextCNN模型

```python
class TextCNN(nn.Module):
    def __init__(self, vocab_size, embed_size, kernel_sizes, num_channels):
        super(TextCNN, self).__init__()

        self.embedding = nn.Embedding(vocab_size, embed_size)
        self.constant_embedding = nn.Embedding(vocab_size, embed_size)

        self.dropout = nn.Dropout(0.5)
        self.decoder = nn.Linear(sum(num_channels), 2)

        self.pool = nn.AdaptiveAvgPool1d(1)
        self.relu = nn.ReLU()

        self.convs = nn.ModuleList()
        for c, k in zip(num_channels, kernel_sizes):
            self.convs.append(nn.Conv1d(2 * embed_size, c, k))

    def forward(self, inputs):
        embeddings = torch.cat((
            self.embedding(inputs),
            self.constant_embedding(inputs)
        ), dim=2)

        embeddings = embeddings.permute(0, 2, 1)

        encoding = torch.cat([
            torch.squeeze(self.relu(self.pool(conv(embeddings))), dim=-1)
            for conv in self.convs
        ], dim=1)

        outputs = self.decoder(self.dropout(encoding))
        return outputs
```

2. 加载两份Glove嵌入

```python
glove_embedding = d2l.TokenEmbedding(
    'glove.6b.100d'
)

embeds = glove_embedding[
    vocab.idx_to_token
]

net.embedding.weight.data.copy_(embeds)

net.constant_embedding.weight.data.copy_(
    embeds
)

net.constant_embedding.weight.requires_grad = False
```

3. 训练TextCNN

```python
num_epochs = 5

    net.parameters(),
    lr=lr
)

    reduction='none'
)

    net,
    train_iter,
    test_iter,
    loss,
    trainer,
    num_epochs,
    devices

```
