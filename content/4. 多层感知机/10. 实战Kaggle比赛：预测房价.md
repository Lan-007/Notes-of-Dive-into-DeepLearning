### 2) 处理数值特征：标准化

房价数据里有数值特征，比如：

```text
LotArea 面积
YearBuilt 建造年份
GarageCars 车库车位数
```

这些特征量纲差别很大。如果不标准化，数值大的特征可能主导训练。

```python
# 找出所有数值型特征列
numeric_features = all_features.dtypes[all_features.dtypes != 'object'].index

# 每列减去均值，再除以标准差
all_features[numeric_features]=all_features[numeric_features].apply(lambda x: (x - x.mean()) / (x.std()))

 # 标准化后，缺失值用 0 填充
all_features[numeric_features] = all_features[numeric_features].fillna(0)
```

## 5. log RMSE 评估函数

```python
def log_rmse(net, features, labels):
	# 限制预测值范围，避免出现log负数 最小值限制为1 最大值不限制
    clipped_preds = torch.clamp(net(features), 1, float('inf'))

	# 均方误差开根号得到RMSE
    rmse = torch.sqrt(loss(torch.log(clipped_preds), torch.log(labels)))

    return rmse.item()  # 转成Python数字返回
```

            optimizer.step()  # 根据梯度更新参数

    return train_ls, test_ls  # 返回训练误差和验证误差

### 7. K折交叉验证

因为训练样本数量有限，使用 K 折交叉验证来评估模型。

```python
def k_fold(k, X_train, y_train, num_epochs, learning_rate,
           weight_decay, batch_size):

    train_l_sum = 0  # 累计每一折最后的训练误差
    valid_l_sum = 0  # 累计每一折最后的验证误差

    for i in range(k):  # 遍历k折
        data = get_k_fold_data(k, i, X_train, y_train)  # 取第i折的数据划分

        net = get_net()  #每一折都创建一个全新的模型

		# 训练当前折模型
        train_ls, valid_ls = train(
	        net,
	         *data,
	         num_epochs,
	         learning_rate,
	         weight_decay,
	         batch_size )

        train_l_sum += train_ls[-1]  # 加上当前折最后一轮训练误差
        valid_l_sum += valid_ls[-1]  # 加上当前折最后一轮验证误差

        print(f'折{i + 1}，训练log rmse{float(train_ls[-1]):f}, '
              f'验证log rmse{float(valid_ls[-1]):f}')  # 打印当前折结果

    return train_l_sum / k, valid_l_sum / k  #返回平均训练误差和平均验证误差
```
