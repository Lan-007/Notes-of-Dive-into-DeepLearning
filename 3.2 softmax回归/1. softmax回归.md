softmax回归：预测类别

预测类别，一般采用独热编码。

仍是线性模型，结构：
```
输入
↓
Linear
↓
输出多个类别分数
↓
Softmax
↓
概率
```
#### 1.网络输出

网络输出：logits，不是概率 
	$o_{1}=w_{11}x_{1}+\cdots+w_{14}x_{4}+b_1$
	$o_{2}=w_{21}x_{1}+\cdots+w_{24}x_{4}+b_2$
	$o_{3}=w_{31}x_{1}+\cdots+w_{34}x_{4}+b_3$
$$\mathbf{o}=\mathbf{W}\mathbf{x}+\mathbf{b}$$
#### 2.softmax：概率

softmax定义：$$\hat{y_{j}}=\frac{\exp(o_{j})}{\sum_{k}\exp(o_{k})}$$
且：$$\sum_{i}\hat{y_{i}}=1$$
设：
```
batch_size = n
输入维度 = d
类别数 = q
```
则：
```
X: (n, d)
W: (d, q)
b: (q,)
O = X @ W + b: (n, q)  每行对应一个样本，每列对应一个类别
```
#### 3.交叉熵损失

独热标签 $y = [0, 0, 1]$

预测概率 $\hat{y} =[0.1, 0.2, 0.7]$

则交叉熵：$$L(\mathbf{w},b)=-\sum_{j}y_{j}\log \hat{y_{j}}$$

只有真实类别那一项保留，$l=-\log(0.7)$

也就是说：分类交叉熵只关心模型给真实类别分配了多少概率。

这就是交叉熵比“是否预测正确”更适合作为训练目标的原因。`accuracy` 只有对/错，不能提供足够连续、可导的优化信号。
$$\frac{\partial l}{\partial o_{j}}=\hat{y_{j}}-y_{j}$$
