
深度学习的 loss 通常不是一个变量的函数，而是很多参数的函数。
梯度是所有偏导数拼成的向量。

1. 自动微分
```python
x = torch.arange(4.0, requires_grad=True)
y = 2 * torch.dot(x, x)
print(y)
# tensor(28., grad_fn=<MulBackward0>)

y.backward()      # 计算梯度
print(x.grad)     # 读取梯度
# tensor([ 0.,  4.,  8., 12.])

x.grad.zero_()
```
2. 通常对标量调用backward()
```python
x.grad.zero_()

y = x * x
# y = [0, 1, 4, 9]

y.sum().backward()
print(x.grad)
# tensor([0., 2., 4., 6.])
```
3. 切断梯度路径
```python
x.grad.zero_()

y = x * x
u = y.detach()
z = u * x

z.sum().backward()
```
