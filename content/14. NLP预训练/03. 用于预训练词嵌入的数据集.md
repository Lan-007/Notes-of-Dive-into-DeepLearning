# 用于预训练词嵌入的数据集

**如何把原始文本数据处理成 word2vec 可以训练的数据集**。

使用 **PTB 数据集**，全称是 Penn Tree Bank。它是一个 NLP 数据集，里面是英文句子。每一行可以看成一句话。

1. 语料库：一个列表，里面每个元素是一句话；每句话又是一个词列表。

```python
sentences = [                                      # 创建一个句子列表
    ['the', 'quick', 'brown', 'fox'],
    ['i', 'love', 'deep', 'learning'],
    ['pytorch', 'is', 'useful']
]
```

2. 词表：把词映射成编号。

$$
w\rightarrow id(w)
$$

```python
tokens = ['i', 'love', 'deep', 'learning']

token_to_idx = {
    'i': 0,
    'love': 1,
    'deep': 2,
    'learning': 3
}

indices = [token_to_idx[token] for token in tokens]
# 用 token_to_idx[token] 查出词的编号
# 最后得到一个编号列表

print(indices)                                     # 输出 [0, 1, 2, 3]
```

3. 丢弃低频词：词表变小，训练更快。去掉噪声词，训练更稳定。
4. 下采样高频词（subsampling）：随机丢弃一部分高频词，例如the

$$
P(w_{i})=max\left( 1-\sqrt{ \frac{t}{f(w_{i})} },0\right)
$$

其中：
- $w_{i}$ ：某个词
- $f(w_{i})$ ：这个词在语料中的频率
- $t$ ：一个很小的阈值，通常如 $10^{-4}$
5. 构造中心词和上下文词

```python
def get_centers_and_contexts(corpus, max_window_size):

    centers = []

    contexts = []             # 上下文词

    for line in corpus:

        if len(line) < 2:     # 句子长度小于 2，就无法构造中心词和上下文词
            continue

        centers += line

            window_size = random.randint(1, max_window_size) # 随机选择窗口大小

            indices = list(range(
                max(0, i - window_size),
                min(len(line), i + 1 + window_size)
            ))
            # min(len(line), i + 1 + window_size) 防止右边越界

            indices.remove(i)             # 删除中心词自己的位置

            contexts.append([line[idx] for idx in indices])

    return centers, contexts
```

7. 小批量读取时padding
8. bathcify

|名称|含义|
|---|---|
|`centers`|中心词编号|
|`contexts_negatives`|上下文词 + 负样本词|
|`masks`|哪些位置有效，哪些是 padding|
|`labels`|哪些是正样本，哪些是负样本|
$eg:$

```text
contexts_negatives = [深度, 香蕉, 汽车, 0, 0]
labels             = [1,   0,    0,    0, 0]
masks              = [1,   1,    1,    0, 0]
```

```python
import torch
def batchify(data):
    # 定义一个函数，把多个样本整理成一个 batch
    # data 是一个列表，里面每个元素是一个训练样本
    # 每个样本形如：
    # (center, context, negative)

    max_len = max(len(context) + len(negative) for _, context, negative in data)
    # 找出最长的 “上下文词 + 负样本词” 长度，用于padding

    centers = []
    contexts_negatives = []
    masks = []
    labels = []

    for center, context, negative in data:

        cur_len = len(context) + len(negative)

        centers.append(center)

        contexts_negatives.append(
            context + negative + [0] * (max_len - cur_len)
        )

        masks.append(
            [1] * cur_len + [0] * (max_len - cur_len)
        )

        labels.append(
            [1] * len(context) + [0] * (max_len - len(context))
        )

    return (
        torch.tensor(centers).reshape((-1, 1)),
        # 形状是 [batch_size, 1]

        torch.tensor(contexts_negatives),
        # 形状是 [batch_size, max_len]
        torch.tensor(masks),
        # 形状是 [batch_size, max_len]
        torch.tensor(labels)
        # 形状是 [batch_size, max_len]
    )
```
