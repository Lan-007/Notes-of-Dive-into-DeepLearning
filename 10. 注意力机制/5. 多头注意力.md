一个注意力很难同时学习不同类型的信息关系，多个 Attention 并行工作，关注不同的信息模式。(语法关系、实体关系、语义关系)
#### 1.多头注意力

单头注意力：$$Attention(Q,K,V)=softmax\left( \frac{QK^T}{\sqrt{ d }} \right)V$$
多头注意力：把一个大的 Attention 拆成多个小 Attention 。
$\space\space\space\space\space\space\space\space eg: d=512$ ，不用 $512$ 维的Attention，而是分 $8$ 个 Head，一个 Head 64维。

有 $h$ 个注意力头，每个头都有自己的一组线性变换：$$\mathbf{W}_{i}^Q​,\mathbf{W}_{i}^K​​,\mathbf{W}_{i}^V​$$第 $i$ 个头计算：                                         $$\mathbf{H}_{i}​=Attention(\mathbf{Q}\mathbf{W}_{i}^Q​,\mathbf{K}\mathbf{W}_{i}^K​​,\mathbf{V}\mathbf{W}_{i}^V​​)$$
然后把所有头的输出拼接起来$$Concat(\mathbf{H}_{1}​,…,\mathbf{H}_{h}​)$$
最后再经过一个线性变换：        $$Output=Concat(\mathbf{H}_{1}​,…,\mathbf{H}_{h}​)\mathbf{W}^O$$
#### 2.维度关系：

每个头都做一次注意力：$softmax\left( \frac{\mathbf{Q}_{i}\mathbf{K}_{i}}{\sqrt{ d_{h} }}​​ \right)\mathbf{V}_{i}​$                   其中 $d_{h}=\frac{d_{model}}{h}$
	也就是每个头的维度通常是总隐藏维度除以头数。
```python
def transpose_qkv(X, num_heads):                         
    X = X.reshape(X.shape[0], X.shape[1], num_heads, -1) # 

    X = X.permute(0, 2, 1, 3)                            # 把头数放到前面

    return X.reshape(-1, X.shape[2], X.shape[3])     
```
原始： $X.shape=(batch\underline{ }size, num\underline{ }steps, num\underline{ }hiddens)$ 
第一步：                $(batch\underline{ }size, num\underline{  }steps, num\underline{ }heads, d_{h})$ 
第二步：                $(batch\underline{ }size, num\underline{ }heads, num\underline{ }steps, d_{h})$
第三步：                $(batch\underline{ }size×num\underline{ }heads, num\underline{ }steps, d_{h}​)$ 
```python
def transpose_output(X, num_heads):                    # X 是多头注意力输出
    X = X.reshape(-1, num_heads, X.shape[1], X.shape[2]) 

    X = X.permute(0, 2, 1, 3)                            

    return X.reshape(X.shape[0], X.shape[1], -1)        
```
注意力输出： $(batch\underline{ }size×num\underline{ }heads, num\underline{ }steps, d_{h}​)$ 
第一步：         $(batch\underline{ }size, num\underline{ }heads, num\underline{ }steps, d_{h})$
第二步：         $(batch\underline{ }size, num\underline{ }queries, num\underline{ }heads, d_{h})$ 
第三步：         $(batch\underline{ }size, num\underline{ }steps, num\underline{ }hiddens)$ 
#### 3.多头注意力类
```python
class MultiHeadAttention(nn.Module):                         # 定义多头注意力层
    def __init__(self, key_size, query_size, value_size,
                 num_hiddens, num_heads, dropout, bias=False, **kwargs): 
        super(MultiHeadAttention, self).__init__(**kwargs)    
        
        self.num_heads = num_heads                            

        self.attention = d2l.DotProductAttention(dropout)  # 使用缩放点积注意力   
        self.W_q = nn.Linear(query_size, num_hiddens, bias=bias)  

        self.W_k = nn.Linear(key_size, num_hiddens, bias=bias)    
        self.W_v = nn.Linear(value_size, num_hiddens, bias=bias) 
        self.W_o = nn.Linear(num_hiddens, num_hiddens, bias=bias) 
        
	def forward(self, queries, keys, values, valid_lens):          # 前向传播
	    queries = transpose_qkv(self.W_q(queries), self.num_heads) 
	    keys = transpose_qkv(self.W_k(keys), self.num_heads)      
	    values = transpose_qkv(self.W_v(values), self.num_heads)  
	
	    if valid_lens is not None:                                 
	        valid_lens = torch.repeat_interleave(                 
	            valid_lens,                                        
	            repeats=self.num_heads,                            
	            dim=0                                              
	        )
	
	    output = self.attention(queries, keys, values, valid_lens) 
	
	    output_concat = transpose_output(output, self.num_heads)   
	
	    return self.W_o(output_concat)                             
```
这里有四个线性层。其中：
- $\mathbf W_q$：生成 Query
- $\mathbf W_k$：生成 Key
- $\mathbf W_v$：生成 Value
- $\mathbf W_o$：融合多个头的输出
#### 4.完整计算流程
$$\mathbf{Q}'=\mathbf{Q}\mathbf{W}_{q}$$$$\mathbf{K}'=\mathbf{K}\mathbf{W}_{k}$$$$\mathbf{V}'=\mathbf{V}\mathbf{W}_{v}$$
然后拆成 $h$ 个头：    $$\mathbf{Q}_{1}',\cdots,\mathbf{Q}_{h}',\mathbf{K}_{1}',\cdots,\mathbf{K}_{h}',\mathbf{V}_{1}',\cdots,\mathbf{V}_{h}'$$
​每个头：$$\mathbf{H}i​=softmax\left( \frac{\mathbf{Q}_{i}'(\mathbf{K}_{i}')^T}{\sqrt{ d_{h} }}​ \right)\mathbf{V}_{i}'$$拼接：$$\mathbf{H}=Concat(\mathbf{H}_1​,…,\mathbf{H}_h​)$$
输出投影：$$\mathbf{O}=\mathbf{H}\mathbf{W}_{o}$$
所以：$$MultiHead(\mathbf{Q},\mathbf{K},\mathbf{V})=Concat(\mathbf{H}_{1}​,…,\mathbf{H}_h​)\mathbf{W}_o​$$
