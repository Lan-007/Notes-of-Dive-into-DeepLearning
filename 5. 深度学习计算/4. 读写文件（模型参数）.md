怎么把张量、模型参数保存到硬盘里；之后怎么重新加载回来。
#### 1.保存张量
```python
import torch

# 单个张量
x = torch.arange(4)
torch.save(x, 'x-file')   # 把 x 保存到 x-file
x2 = torch.load('x-file') # 从 x-file 中读取张量，赋值给 x2

# 多个张量
y = torch.zeros(4)
torch.save([x, y], 'x-files')
x2, y2 = torch.load('x-files')

# 用字典保存
mydict = {'x':x, 'y':y}
torch.save(mydict, 'mydict')
mydict2 = torch.load('mydict')
```
#### 2.保存参数
```python
from torch import nn

class MLP(nn.Module):                       
    def __init__(self):                      
        super().__init__()                    

        self.hidden = nn.Linear(20, 256)     
        self.output = nn.Linear(256, 10)     

    def forward(self, x):                     
        x = torch.relu(self.hidden(x))        
        return self.output(x)                 

net = MLP()

# 保存参数
torch.save(net.state_dict(), 'mlp.params')  # 保存模型参数字典

# 加载参数
clone = MLP()

clone.load_state_dict(torch.load('mlp.params')) # 读取参数

clone.eval() # 切换到评估模式
```
### 3.保存checkpoint（训练状态）
```python
checkpoint = {                                 
    'model_state_dict': net.state_dict(),            # 模型参数
    'optimizer_state_dict': optimizer.state_dict(),  # 优化器状态
    'epoch': epoch,                                  # 当前训练轮数
    'loss': loss_value                               # 当前损失
}

torch.save(checkpoint, 'checkpoint.pth') 

checkpoint = torch.load('checkpoint.pth')  

net.load_state_dict(checkpoint['model_state_dict'])            # 加载模型参数
optimizer.load_state_dict(checkpoint['optimizer_state_dict'])  # 加载优化器状态

start_epoch = checkpoint['epoch']               # 读取训练到第几轮

loss_value = checkpoint['loss']                 # 读取保存时的损失
```
