# 暂退法（dropout）

也是正则化方法。

思想：不限制参数，而是随机丢掉神经元，不局限于某几个神经元。

## 1. Dropout

训练时：随机关闭一些神经元。使得每个神经元都必须学会独立提取信息。

通常放在隐藏层，不放输入层，防止破坏原始信息。

以概率 p 把神经元置为 0；以概率 1-p 保留神经元，保留的神经元除以 1-p （保持期望值）

## 2. Dropout简洁实现

```python
net = nn.Sequential(
    nn.Flatten(),
    nn.Linear(784, 256),
    nn.ReLU(),
    nn.Dropout(0.2),      # 训练时随机丢弃 20% 的隐藏单元，测试时自动关闭
    nn.Linear(256, 256),  # 第二层全连接：256 -> 256
    nn.ReLU(),
    nn.Dropout(0.5),      # 训练时随机丢弃 50% 的隐藏单元，测试时自动关闭
    nn.Linear(256, 10)    # 输出层：256 -> 10
)
```

PyTorch 的 `nn.Dropout` 会自动根据：net.train()、net.eval()决定是否启用 Dropout。
