Transformer 的特点是：**完全基于注意力机制，不再依赖 RNN 或 CNN 来处理序列**。
#### 1.整体结构

Transformer 仍然是一个 **编码器-解码器架构**：
$源语言句子 -> Encoder -> 编码表示 -> Decoder -> 目标语言句子$

Transformer Encoder 负责理解输入句子。
$输入 → Embedding → Encoder Block × N$

Transformer Decoder 负责一步步生成输出句子。
$输出 → Embedding → Decoder Block × N → 预测$
#### 2.Encoder Block 

每个编码器块包含两个子层：多头自注意力、基于位置的前馈网络FFN。每个子层外面都有Dropout、残差连接、LayerNorm。

结构是：
$输入  X -> 多头自注意力 -> AddNorm -> FFN -> AddNorm -> 输出$
###### 1)多头注意力

注意力层负责让不同位置之间交换信息。

输入：$X$
生成：$$Q=XW_{Q}$$
$$K=XW_{K}$$
$$V=XW_{V}$$
计算：$$\mathbf{H}_{i}​=softmax\left( \frac{\mathbf{Q}_{i}\mathbf{K}_{i}^T}{\sqrt{ d_{h} }}​​ \right)\mathbf{V}_{i}$$
$$MultiHead(\mathbf{Q},\mathbf{K},\mathbf{V})=Concat(\mathbf{H}_{1},…,\mathbf{H}_{h}​)\mathbf{W}_{o}​$$
得到每个token融合后上下文的表示。
##### 2)残差连接
$$X+Attention(X)$$
作用：保留原始输入信息、让梯度更容易通过深层网络传播。
##### 3)Layer Normalization

某些token维度间数值差异很大，LayerNorm 让均值接近0，方差接近1，可以稳定梯度。$$Y=LayerNorm(X+Attention(X)) $$
##### 4)Feed Forward Network(FFN)

FFN 负责对每个位置的表示进行非线性变换。

结构：$Linear \to Activation \to Linear$

基于位置的前馈网络 FFN：分别处理每个token自己的特征变换，而不是token之间的信息交流
$$FFN(\mathbf{x})=\mathbf{W}_{2}​\sigma(\mathbf{W}_{1}​\mathbf{x}+\mathbf{b}_1​)+\mathbf{b}_{2}​$$
其中：
- $\mathbf x$：某个 token 的隐藏表示
- $\sigma$：激活函数，比如 ReLU
$$Z=LayerNorm⁡(Y+FFN⁡(Y))$$
这里：
- $\mathbf Y$：经过自注意力后的中间结果
- $\mathbf Z$：编码器块输出
- $\operatorname{FFN}$：前馈网络
```python
class EncoderBlock(nn.Module):                                      
    def __init__(self, key_size, query_size, value_size, num_hiddens,
                 norm_shape, ffn_num_input, ffn_num_hiddens,
                 num_heads, dropout, use_bias=False, **kwargs):      
        super(EncoderBlock, self).__init__(**kwargs)                 

        self.attention = d2l.MultiHeadAttention(                   
            key_size, query_size, value_size,
            num_hiddens, num_heads, dropout, use_bias
        )

        self.addnorm1 = AddNorm(norm_shape, dropout)               

        self.ffn = PositionWiseFFN(                                
            ffn_num_input, ffn_num_hiddens, num_hiddens
        )

        self.addnorm2 = AddNorm(norm_shape, dropout)              

    def forward(self, X, valid_lens):                             
        Y = self.addnorm1(                                         
            X,                                                    
            self.attention(X, X, X, valid_lens)                     
        )

        return self.addnorm2(Y, self.ffn(Y))                       
```
#### 4.Transformer Encoder

Transformer 编码器由多个相同的编码器块堆叠而成。
$$\mathbf{X}_{0}​=Embedding(tokens)+\mathbf{P}$$
$$X_{l}=EncoderBlock_{l}​(\mathbf{X}_{l-1})$$
```python
class TransformerEncoder(d2l.Encoder):
    def __init__(
        self,
        vocab_size,
        key_size,
        query_size,
        value_size,
        num_hiddens,
        norm_shape,
        ffn_num_input,
        ffn_num_hiddens,
        num_heads,
        num_layers,
        dropout
    ):
        super().__init__()

        self.num_hiddens = num_hiddens

        self.embedding = nn.Embedding(
            vocab_size, num_hiddens
        )

        self.pos_encoding = d2l.PositionalEncoding(
            num_hiddens, dropout
        )

        self.blks = nn.Sequential()

        for i in range(num_layers):
            self.blks.add_module(
                f"block{i}",
                EncoderBlock(
                    key_size,
                    query_size,
                    value_size,
                    num_hiddens,
                    norm_shape,
                    ffn_num_input,
                    ffn_num_hiddens,
                    num_heads,
                    dropout
                )
            )
```

#### 5.Decoder Block 解码器块

解码器块有三个部分：掩蔽多头自注意力、编码器-解码器注意力、前馈网络
结构：$目标序列输入 -> Masked Self-Attention -> AddNorm -> Encoder-Decoder Attention -> AddNorm -> FFN -> AddNorm -> 输出$
解码器状态：
`state = [ enc_outputs, enc_valid_lens, cache ]`

|位置|内容|
|---|---|
|`state[0]`|编码器输出|
|`state[1]`|源序列有效长度|
|`state[2]`|每层解码器的历史缓存|
##### 1)掩蔽自注意力Masked Self-Attention
$$Q=XW_{Q}$$$$K=XW_{K}$$$$V=XW_{V}$$
$$Attention(Q,K,V)=softmax\left( \frac{QK^T+M}{\sqrt{ d }}​ \right)V$$
- M：是 mask 矩阵，softmax之后对应位置为0.
##### 2)Encoder-Decoder Attention(Cross Attention) 交叉注意力
$$\mathbf{Z}=AddNorm(\mathbf{Y},Attention(\mathbf{Q}=\mathbf{Y},\mathbf{K}=\mathbf{E},\mathbf{V}=\mathbf{E}))$$
##### 3)FFN前馈网络
$$\mathbf{O}=AddNorm(\mathbf{Z},FFN(\mathbf{Z}))$$
```python
class DecoderBlock(nn.Module):                                    
    def __init__(self, key_size, query_size, value_size, num_hiddens,
                 norm_shape, ffn_num_input, ffn_num_hiddens,
                 num_heads, dropout, i, **kwargs):                  
        super(DecoderBlock, self).__init__(**kwargs)              
        self.i = i                                         # 当前块编号

        self.attention1 = d2l.MultiHeadAttention(...)      # 掩蔽自注意力

        self.addnorm1 = AddNorm(norm_shape, dropout)       # 第一个 AddNorm

        self.attention2 = d2l.MultiHeadAttention(...)      # 编码器-解码器注意力

        self.addnorm2 = AddNorm(norm_shape, dropout)       # 第二个 AddNorm

        self.ffn = PositionWiseFFN(...)                     # 前馈网络

        self.addnorm3 = AddNorm(norm_shape, dropout)       # 第三个 AddNorm
    def forward:
	    X2 = self.attention1(X, key_values, key_values, dec_valid_lens)      
	
		Y = self.addnorm1(X, X2)                               
		
		Y2 = self.attention2(Y, enc_outputs, enc_outputs, enc_valid_lens)  
		
		Z = self.addnorm2(Y, Y2)                                         
		
		return self.addnorm3(Z, self.ffn(Z)), state             
```
#### 6.Transformer Decoder

解码器结构：`Embedding + Positional Encoding -> DecoderBlock 1 -> DecoderBlock 2 -> ... -> DecoderBlock N -> Linear(vocab_size)`
```python
class TransformerDecoder(d2l.AttentionDecoder):
    def __init__(
        self,
        vocab_size,
        key_size,
        query_size,
        value_size,
        num_hiddens,
        norm_shape,
        ffn_num_input,
        ffn_num_hiddens,
        num_heads,
        num_layers,
        dropout
    ):
        super().__init__()

        self.num_hiddens = num_hiddens
        self.num_layers = num_layers

        self.embedding = nn.Embedding(
            vocab_size, num_hiddens
        )

        self.pos_encoding = d2l.PositionalEncoding(
            num_hiddens, dropout
        )

        self.blks = nn.Sequential()

        for i in range(num_layers):
            self.blks.add_module(
                f"block{i}",
                DecoderBlock(
                    key_size,
                    query_size,
                    value_size,
                    num_hiddens,
                    norm_shape,
                    ffn_num_input,
                    ffn_num_hiddens,
                    num_heads,
                    dropout,
                    i
                )
            )

        self.dense = nn.Linear(
            num_hiddens, vocab_size
        )
```

    ffn_num_hiddens,

)

net = d2l.EncoderDecoder(

)
